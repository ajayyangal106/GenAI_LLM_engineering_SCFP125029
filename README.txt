Lab 6 - Tools and Tool Calling

1. Activate .venv.
2. Install requirements: python -m pip install -r requirements.txt
3. Create .env from .env.example and add GROQ_API_KEY.
4. Run each file from the Lab6 folder.

Example:
python exercise_1_order_status.py

Exercises 4 uses sample weather data so no weather API key is required.
